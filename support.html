Trung Tâm Hỗ Trợ

Giải đáp các thắc mắc về cài đặt mod dịch thuật, xử lý sự cố link tải Google Drive và liên hệ trực tiếp với Admin.

Câu Hỏi Thường Gặp (FAQ)

Các vướng mắc phổ biến khi tải và sử dụng bản dịch tại Ykimi

01

Cách cài đặt các bản Mod Tiếng Việt?

Mỗi bản mod đều được nén dưới dạng file .zip hoặc .rar. Bạn tải về, giải nén và chép đè vào thư mục gốc chứa game của bạn (Ví dụ: Steam/steamapps/common/[Tên Game]/...).

02

Lỗi Google Drive "Over quota / Quá giới hạn"?

Nếu link Drive bị giới hạn tải trong 24h, bạn hãy đăng nhập tài khoản Google của mình, bấm vào tùy chọn "Tạo bản sao" (Make a copy) để chuyển file về Drive cá nhân rồi tải bản sao đó về bình thường.

03

Game bị Crash (văng game) hoặc ô vuông lỗi font?

Vui lòng kiểm tra lại phiên bản game (Version) xem có đúng với thông tin ghi trên bản mod hay không. Khi nhà phát hành tung bản vá (Patch) mới, bản mod cũ có thể tạm thời mất tương thích.

04

Cách báo lỗi Link hỏng hoặc xin hỗ trợ kỹ thuật?

Nếu phát hiện link bị die hoặc file gặp sự cố giải nén, hãy dùng nút liên hệ phía bên dưới để gửi tin nhắn đến Admin kèm theo tên game và ảnh chụp lỗi.

Bạn vẫn cần sự giúp đỡ khác?

Đội ngũ dịch thuật và hỗ trợ kỹ thuật luôn sẵn sàng hỗ trợ bạn qua kênh liên hệ trực tiếp.
