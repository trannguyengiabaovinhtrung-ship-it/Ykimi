Trung Tâm Hỗ Trợ

Hướng dẫn cài đặt mod, khắc phục lỗi link tải và liên hệ hỗ trợ.

01

Cách cài đặt file Mod dịch thuật?

Tải file `.zip` hoặc `.rar` về máy, giải nén và chép đè các thư mục/file data vào thư mục gốc chứa game của bạn (Ví dụ: Steam/steamapps/common/...).

02

Lỗi Drive "Quota Exceeded"?

Nếu Google Drive báo giới hạn lượt tải, bạn chỉ cần đăng nhập tài khoản Drive của mình, chọn "Tạo bản sao" (Make a copy) về Drive cá nhân rồi tải bản sao đó về.

03

Game bị Crash hoặc lỗi Font?

Kiểm tra xem phiên bản game đang chơi có khớp với phiên bản bản mod hay không. Nếu game vừa update bản vá mới, bản mod có thể cần vài ngày để tác giả cập nhật.

04

Báo lỗi Link tải hỏng?

Nếu gặp link Google Drive bị xóa hoặc hỏng, vui lòng liên hệ trực tiếp Admin qua nút bên dưới để được kiểm tra và reup link mới.

Vẫn cần trợ giúp thêm?

Nhắn tin trực tiếp cho Admin để được hỗ trợ kỹ thuật nhanh nhất.
