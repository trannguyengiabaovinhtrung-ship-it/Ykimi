Các câu hỏi thường gặp và hướng dẫn khắc phục sự cố khi cài đặt mod tại Ykimi

01. Hướng dẫn cài đặt file Mod dịch thuật?

Hầu hết các bản mod đều nén dưới dạng file `.zip` hoặc `.rar`. Bạn chỉ cần nén/tải về, mở file đọc `ReadMe.txt` (nếu có) và chép đè các file data vào thư mục cài đặt gốc của Game (ví dụ: `Steam/steamapps/common/...`).

02. Link Google Drive bị báo lỗi quá giới hạn lượt tải?

Nếu gặp lỗi "Quota exceeded", bạn chỉ cần đăng nhập tài khoản Google Drive của mình, bấm chọn **Tạo bản sao (Make a copy)** file đó vào Drive cá nhân rồi tải bản sao về là thành công.

03. Game bị văng (Crash) hoặc mất font Tiếng Việt?

Hãy kiểm tra lại phiên bản Game (Version) của bạn có khớp với phiên bản ghi trên bản Mod hay không. Nếu game vừa cập nhật patch mới, bản mod cũ có thể tạm thời không tương thích và cần chờ tác giả update.
